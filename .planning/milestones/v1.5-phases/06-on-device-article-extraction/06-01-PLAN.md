## Phase Goal

Ordinary http(s) articles load by fetching the page on-device and extracting readable Markdown locally, so reading does not depend on a remote Markdown proxy.

<objective>
Prove the architecture end-to-end: pin jsoup 1.23.1 plus desugar_jdk_libs_nio 2.1.5, GET the origin (D-01, D-04, D-09), strip chrome (D-07), convert the article node with existing HtmlToMarkdown (D-06), and key OkHttp cache on the origin URL (D-02, D-15). Android-only extract (D-03). HTTP plus HTML only (D-10). READ-04 and READ-01. Tables, footnotes, ordered lists, thin-extract fail, UA retry, and D-13 copy land in 06-02 and 06-03.
Purpose: Every ordinary web read today goes through a remote proxy that returns 401 (GitHub #54). The thinnest fix is origin GET plus an in-repo extract on the existing reader path.
Output: ArticleExtractor, origin fetch, HTML-only parse, JVM fixtures for chrome and relative images
</objective>
